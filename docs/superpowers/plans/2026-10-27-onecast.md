# OneCast Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Windows app that takes one mic (ASIO M-Track Solo or any WASAPI capture device), runs it through a built-in voice chain (pre-gain, HPF, AI/Light noise suppression, gate, EQ, compressor, de-esser, -1 dBFS limiter) and renders it to "CABLE Input (VB-Audio Virtual Cable)" with the lowest latency it can.

**Architecture:** JUCE `AudioDeviceManager` opens the mic input-only; its callback runs a pure, unit-tested mono `VoiceChain` and writes stereo into LiveVocal's lock-free `RingBuffer`; LiveVocal's `WasapiOutputDevice` render thread drains it through `DriftCompensatedReader` into CABLE Input. DSP (`Source/Dsp`) knows nothing about devices; the engine (`Source/Audio`) knows nothing about UI; the UI (`Source/UI` + `MainComponent`) only talks to the engine and the session layer.

**Tech Stack:** JUCE 8.0.5 (juce_audio_devices, juce_dsp, juce_gui_extra), C++20, CMake, MSVC (Visual Studio 18 2026), RNNoise 0.2 (C, BSD-3), Win32 (RegisterHotKey, HKCU Run).

**Spec:** `docs/superpowers/specs/2026-10-27-onecast-design.md` (Vietnamese). Executors read both. The reference implementation for every reused piece is `D:\Projects\LiveVocal` (read-only: never modify it).

## Review Focus

1. **Hours-long sessions.** The M-Track clock and VB-Cable's clock drift apart. The output backlog must stay flat with no underruns. Covered by the ported `DriftCompensatedReader` tests (Task 1) and the 30-minute probe soak (Task 15).
2. **Mic or interface unplugged mid-session, or CABLE Input vanishing.** The app recovers to the *same* device and never switches to another mic or to the default output. Covered by the ported `DeviceRecovery` tests (Task 1), the engine tests `setOutputDevice("")` and "vanished id never falls back" (Task 11), and the real unplug test (Task 15).
3. **Device rates other than 48 kHz** (44.1 kHz USB mics, 96 kHz interfaces). AI must resample, Light must keep ≤ 6 ms, and the latency report must stay true. Covered by tests at 44100 and 96000 in Tasks 4, 5 and 10.
4. **Irregular block sizes** (WASAPI hands 441, 480, odd or 1-sample blocks). Output must be identical whatever the blocking. Covered by block-size-independence tests in Tasks 2, 4, 5 and 10.
5. **Hot input** (shouting, mic knocks, ADC clipping, NaN from a driver). The ceiling must hold at maximum gains, NaN must not poison the chain, and the user must be told about hardware clipping. Covered by "never exceeds ceiling at max gains" and "non-finite input" (Task 10) and "raw clip flag" (Task 11).

class NoiseGate   // downward expander with hysteresis and hold, peak detector
{
public:
    static constexpr float hysteresisDb = 4.0f, rangeDb = 30.0f;
    static constexpr float attackMs = 1.0f, holdMs = 150.0f, releaseMs = 150.0f;
    void prepare (double sampleRate);

    float getGainReductionDb() const noexcept; // <= 0, atomic
};
class Compressor  // feed-forward, RMS-like level detector, soft knee
{
public:
    static constexpr float kneeDb = 6.0f, attackMs = 8.0f, releaseMs = 120.0f;
    static float staticCurveDb (float inDb, float thresholdDb, float ratio, float kneeDb) noexcept;
    void prepare (double sampleRate);
    void reset() noexcept;
    void setParams (float thresholdDb, float ratio, float makeupDb) noexcept;  // smoothed
    void process (float* samples, int numSamples) noexcept;
    float getGainReductionDb() const noexcept; // <= 0, excludes makeup, atomic
};
class DeEsser     // split band: only the 5-9 kHz region is turned down, only while it dominates
{
public:
    static constexpr double bandLowHz = 5000.0, bandHighHz = 9000.0;
    static constexpr float maxReductionDb = 12.0f;     // at amount 100 %
    void prepare (double sampleRate);
    void reset() noexcept;
    void setAmount (float percent) noexcept;
    void process (float* samples, int numSamples) noexcept;

### Task 4: Light noise suppression (SpectralDenoiser)

**Files:** Create `Source/Dsp/SpectralDenoiser.h/.cpp`, `Tests/SpectralTests.cpp` (category `spectral`).

**Interfaces:**
- Consumes: `TestSignals`, `juce::dsp::FFT`.
- Produces:
```cpp
class SpectralDenoiser
{
public:
    static constexpr float maxAttenuationDb = 18.0f;   // spectral floor at amount 100 %
    void prepare (double sampleRate, int maxBlockSize); // FFT 256 at <= 50 kHz, 512 above
    void reset() noexcept;
    void setAmount (float percent) noexcept;            // smoothed; 0 = delayed pass-through
    void process (float* samples, int numSamples) noexcept;   // any block size
    int  getLatencySamples() const noexcept;            // constant after prepare, <= 0.006 * sr
};
```
Approach: streaming STFT, hop = FFT/4, sqrt-Hann analysis and synthesis windows normalised for perfect reconstruction; adaptive noise estimate (minimum statistics or MCRA) per bin; decision-directed Wiener gain, smoothed over time and frequency, floored at `-maxAttenuationDb * amount / 100`. Input/output FIFOs make it block-size independent.

- [ ] **Step 1: Write the failing tests:**
  - `"zero amount is a pure delay"`: amount 0 on the speech fixture → output[i + L] equals input[i] within 1e-4, L = `getLatencySamples()`.
